# Memory Card Game

A responsive browser-based memory game where players flip cards and try to find all matching pairs. The project focuses on simple game logic, DOM state management, click handling, CSS Grid, and card-flip animations.

## Features

- 16-card game board with 8 matching pairs
- Random card shuffling for every new game
- Click-to-flip card interactions
- Matching-pair detection
- Automatic flipping back for incorrect pairs
- Move counter
- Match counter
- Restart button
- Completion message when all pairs are matched
- Responsive CSS Grid layout
- Card-flip animations
- Keyboard-accessible card buttons
- ARIA labels and live status updates
- Reduced-motion support
- Mobile-first responsive design

## Tech Stack

- HTML5
- Tailwind CSS via CDN
- Custom CSS
- Vanilla JavaScript
- DOM API
- CSS Grid
- CSS 3D transforms
